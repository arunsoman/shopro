## 🚀 Getting Started

1. **Login**: Use any of the PINs above on the POS or KDS terminal.
2. **Floor Plan**: Log in as **Hannah Host** to see current table occupancy.
3. **Take Orders**: Log in as **Sam Server** to start a new dining session.
4. **Kitchen Flow**: Log in as **Stan Station** to manage incoming tickets on the KDS.
5. **Insights**: Log in as **Alex Owner** to view the performance dashboard.

> **Security Notice**: These are default demonstration credentials. In a production environment, please ensure all PINs are updated immediately via the Admin Security panel.
